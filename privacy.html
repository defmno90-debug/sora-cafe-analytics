Sora Cafe Analytics プライバシーポリシー

本アプリは、YouTubeチャンネル「Sora Café Sounds」の運営者が、自身のチャンネルの統計情報を確認するためだけに使用する個人用ツールです。

  1. 取得する情報：YouTube Data API、YouTube Analytics API、YouTube Reporting API を通じて、運営者自身のチャンネルの動画情報と統計情報（再生回数、視聴時間、インプレッション、登録者の増減など）を読み取り専用で取得します。
  2. 利用目的：運営者自身のチャンネルの分析と、動画制作の改善のみに使用します。
  3. 保存：取得したデータは運営者のコンピューター内にのみ保存し、外部のサーバーには送信しません。
  4. 第三者への提供：取得したデータを第三者に提供・販売することはありません。
  5. 運営者以外の利用：本アプリは運営者以外のユーザーのデータを取得しません。
  6. アクセスの取り消し：Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセス権を取り消せます。
  7. YouTube API サービス：本アプリは YouTube API サービスを使用しています。YouTube 利用規約および Google プライバシーポリシーが適用されます。
